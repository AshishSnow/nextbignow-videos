# The writers' room — episode queue

Scripts are written ahead, checked (`tools/story_check.py`: 7/7 R-gates + all S-gates) and reviewed by a fresh pair of eyes
before anyone renders (STORY.md §8). The R&D task keeps **≥ 3 REVIEWED** episodes here; the episode task builds the top one.

Folder per episode: `queue/NN-slug/` with `vo_lines.py` (SERIES / PART / EP + LINES), `shots.md` (storyboard: one row per line)
and a `SOURCES-*.md` (every number and quote with link + date). After posting: move the folder to `done/` and fill the row below.

Pre-flight: `python3 studio/tools/board_check.py queue/<NN-slug>` (R&D Tooling run, 31 Oct) — rows ↔ lines, missing template assets
(= the build brief), caption sizes, static rows, signature beats; `--all queue` for the whole room; `--strict` once the assets are written.
Writers: keep `say()` captions ≤ ~22 characters (or two `say()` lines), name sets by their registered name (`bedroom90s`, not "bedroom"),
and put every new asset the header lists into at least one row.

Status: DRAFT → REVIEWED → BUILDING → BUILT (post time IST). A two-part Part 2 is due in the **same IST slot one day after
Part 1**: the episode task builds it on the **very next run** after Part 1 was built (since 31 Oct the task fires once a day, 21:05 UTC / 02:35 IST;
waiting for the "second" run would post it 48 h later and break Part 1's spoken "Part two tomorrow"). If Part 1 was never posted, Part 2 waits.
