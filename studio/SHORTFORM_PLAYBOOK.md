# OMB Short-Form Playbook (Lego-brick method, adopted 24 Nov 2026)

Content = data + psychology. Every reel is a stack of 11 bricks. Keep most bricks that already work, change 1–3 on purpose, and write down which brick was tested.

## The 11 bricks (fill this sheet in `projects/<slug>/BRICKS.md` before writing vo_lines)
| Brick | What to decide | OMB default |
|---|---|---|
| 1 Format | Breakdown / Scenario ("you're the customer…") / Hero's journey / Experiment / Myth vs fact / List | rotate; never two of the same format back to back |
| 2 Topic | the subject (company, trick, idea) | must be on-target: business, money, marketing |
| 3 Seed | the one-line premise a stranger repeats to a friend | write it first, ≤12 words |
| 4 Substance | the facts / numbers / quote that make it feel true | 2 sources each, one big number |
| 5 Text hook | words on frame 1 (MOST important) | ≤6 words, a contradiction or number; readable in 1 s |
| 6 Visual hook | what moves on frame 1 | a prop already in motion that shows the puzzle (price tags, B- grade, $20B cheque) |
| 7 Spoken hook | first sentence | says the same promise as the text hook in different words; no "Pick one / We all know" |
| 8 Story structure | rehooks every 5–7 s, Q&A turns, payoff last calling back to the hook | end the moment the payoff lands |
| 9 CTA | what we want next | soft: final slide line "FOLLOW FOR DAILY BUSINESS BREAKDOWNS" + caption question; agency offer only in bio/caption, never in voice |
| 10 Visual layout | ESSAY look: cream + dark slides, Anton caps, one accent block | colour = series |
| 11 Elements | signature bits: page counter, series label, shakes, SFX hits | keep |

## Hook rules (text > visual > spoken)
- Frame 1 must make sense with the sound OFF.
- Text hook and visual hook must agree (number on screen + the object it's about).
- Spoken hook lands the surprise in the first 3 s; first useful fact by ~4 s.
- Best patterns so far: hidden-cost/contradiction ("Nobody chose this price…"), underdog number ("Zero points…").

## Improvement loop (one hypothesis per reel)
Each reel's BRICKS.md ends with: `HYPOTHESIS: changing <brick> from X to Y should raise <views/retention>`.
Every day: read views per reel (Metricool / IG grid), log them below, keep the winning brick, swap a losing one.

## Script system (strategy -> execution), added 24 Nov 2026
Strategy (decide before writing):
1. Purpose: one goal per reel (follow / save / comment) and the one thing the viewer should remember.
2. Audience: small-business owners and curious US viewers; name their pain ("customers can't decide", "ads cost too much") in their words.
3. Structure: HOOK -> BUILD -> DELIVER -> CLOSE.
4. Value every line: each line must teach, surprise or move the story. Value early (first fact by ~4 s), value often.
5. Drive action: close with one clear, simple thing to do ("take one away"), said with conviction.
Execution:
1. Research: real study / case, two sources, and the honest limits (a caveat line builds trust and is a free rehook).
2. Hook: attention in the first seconds via curiosity or a bold statement; make them need the answer.
3. Build: clear sections, natural conversational flow, support with a story or example.
4. Refine: cut fluff and filler, read it out loud, keep it crisp.
5. Test: log retention/views, iterate (Results log above).
Script sheet = BRICKS.md + a line-by-line tag: each vo line tagged HOOK / BUILD / DELIVER / CLOSE and with its value (fact, turn, or takeaway). Any line with no value gets cut.
