# PACKAGING
Type: tip
Idea: Mattress makers let each store rename the same bed, so you can't price-shop it.
Title: Same Mattress, Different Name at Every Store
Cover line: SAME BED. NEW NAME.
Reward: The same mattress can have a different name at every store.
Gap: Why would they do that?
Payoff / last line: So compare the brand line and the comfort level, not the name.
Send line: Send this to anyone buying a bed this year.
Sources: Serta help center: "We allow retailers to choose and add a different showroom name to the mattresses they are selling" and compare by "product line and comfort level"; Consumers' Checkbook (mattress stores guide): the industry "has carefully created a system that makes it impossible to shop around."
Word budget: ~80 words / ~31 s
